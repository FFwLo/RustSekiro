Join in five steps

  1. Own the game. Sekiro from Steam (patch 1.06), Windows, Rust and Python 3. Nobody shares game files: you extract your own.

  2. Fork and clone, then add the project as upstream.

    git remote add upstream https://github.com/FFwLo/RustSekiro.git

  3. Extract your data and check the setup until the doctor says ready.

    powershell -ExecutionPolicy Bypass -File tools\extract.ps1
git config core.hooksPath .githooks
python tools/doctor.py

  4. Pick a row and start it. New here? Take a B row. start claims it under your GitHub name and makes your own worktree.

    python tools/row.py
python tools/row.py start B3 --agent wren

  5. Check and submit. submit pushes to your fork and opens the pull request with your test result filled in. The owner merges, and the row moves to Done by itself.

    python tools/row.py check
python tools/row.py submit "what changed, in one line"

With an agent: it reads AGENTS.md by itself. Claude Code also loads the repository's rsekiro-row skill: say "do an RSekiro row".
