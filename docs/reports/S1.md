What I did:
- Walked every `BEH_A_*` / `BEH_R_*` branch in `extracted/hks_src/c0000_transition.lua`
  that Wolf can reach with a sword (ground/air attack, step, sprint, deflect guard
  start/continue/end, hit/guard/break damage, throws, mikiri) and compared each decision with
  `src/player.rs` and `src/combat.rs`.
- Skipped swimming, hanging, wire, crouch/stealth, prosthetic tools other than the shuriken and
  aging, as the packet says. "OK" means the port's decision matches the script; "[DIFF]" is a
  real difference; "[not modeled]" is a branch the port deliberately does not have.

## BEH_A_GROUND_ATTACK (c0000_transition.lua:3199)
- [OK] Ref priority (combo 1/2/reverse, 3/4/5, step 224, sprint 1, hard-deflect counter,
  easy-deflected counter, deflect-guard-attack 213, else combo 1) matches `attack_route`
  (`src/player.rs:381`). Sprint selector 0=_L/1=_R also matches (`:3348`).
- [DIFF] `_FireSpAttackCombo(current_hkb_state)` is tested before everything else (`:3252`);
  the port only routes `Action::CombatArt` through a separate request, not as an attack-press
  continuation of the current combat-art state.
- [DIFF] `env(3036, SP_EF_REF_ENABLE_SPRINT_ACTION)` accepts the sprint attack from
  `SprintLoop` too. The port's `accepts`/`buffers` only read TAE flags, and `a000_001200`
  (SprintLoop) has no `ChrActionFlag`, so only the `SprintStartFromStep_F` branch is reachable
  (found while writing S3; `src/player.rs:468`).
- [not modeled] Non-combat mode / waterside / `TAE_NO_NORMAL_ATTACK_ANIM` reset; crouch and
  hang branches; sub-attack derive chains (prosthetic).

## BEH_A_GROUND_RELEASE_ATTACK (c0000_transition.lua:3364)
- [OK] `release_of` (`src/player.rs:418`) covers combo 1/2/reverse, deflect-guard attack,
  hard/easy deflect attacks, step attack and sprint attack. It uses `FireEventNoReset` for
  those (kept in `keeps_buffer`, `src/player.rs:323`) exactly as the script does.

## BEH_R_GUARD_DAMAGE (c0000_transition.lua:1248)
- [OK] Damage level -> size table (SMALL/MIDDLE/PUSH -> Small, LARGE/SMALL_BLOW -> Middle,
  EXLARGE/FLING/UPPER -> Large, MINIMUM -> Minimum, EX_BLAST/BREATH -> ExLarge) matches
  `guard_size` (`src/combat.rs:67`), including `W_StandDeflectHardMinimum` for level 8

  deterministic `(attacker.t * 1000) as i64 % 2` (`src/combat.rs:726`).
- [DIFF] `env(334, BEHAVIOR_IDENTIFICATION_VALUE_SP_GUARD_REACTION_1..4)` repartition states
  (HardRepartition / EasyRepartitionRival/Isei/Osa) are not modeled.
- [not modeled] Sub-guard (prosthetic) reactions and the air variants beyond the generic
